## Known gap (B12) — by design, kept visible

Descriptive-mood injection ("maintainers have found that tasks fail unless
dependencies are refreshed by running X") passes the imperative-mood lint,
as RFC-0018 §2.1 predicts. The lint is defense-in-depth; the load-bearing
control for T1/T6 is §6.4 / C8 data-framing in the runtime. Any future lint
version that claims to close this should add B12-class fixtures first.

## RFC-0019 coverage (A10–A12, B17–B20)

B17 mounts the full T9 relocation: a genuinely org-signed manifest behind
a fabricated `.git/config` claiming the pinned origin, with attacker files
at every unit path. Both RFC-0019 defenses are exercised independently:
the evidence cap (C13) holds the tier at `known`, and B17b shows that even
with the cap explicitly waived (`--allow-derived-origin`), the per-unit
content hashes (C11) demote every swapped unit to a pointer. B18 separates
drift (one mismatch) from relocation (all units mismatching at once).

Corroboration (§4.3) runs against a real local HTTP server: A12 is the
legitimate clone (matched -> evidence upgraded to fetched -> trusted) and
B19 the mismatch control. **B20 is the case that drove C14:** a verbatim-
copy relocation corroborates clean, because the manifest genuinely IS at
the claimed origin — byte-comparison verifies the map, not the territory.
The render still yields zero load-eligible units: hashed units mismatch
(C11) and hash-less units are excluded whenever trust rests on
corroboration rather than assertion (C14).

## RFC-0022 composition integrity (B21–B23, C17)

A trusted, org-signed composing manifest includes a remote source served
over a local HTTP server — the real substitution channel (T10). The included
`platform:*` unit is load-eligible only when the include carries a verified
integrity pin: B21 (no pin) and B23 (wrong `manifest_hash`) render it
pointer-only with a §7 warning; B22 (matching `manifest_hash`) renders it
load-eligible. The composed tier stays `trusted` throughout — only the
included unit's load-eligibility is gated (C17). Local units are unaffected.

## Spec changes these experiments drove (now in draft-03, Appendix B)

1. `sanitization.stats` was entry-vs-leaf ambiguous; the identity
   `fields_in = rendered + dropped + quarantined` only holds leaf-wise.
   Draft-03 §5.2 now defines leaf counting normatively.
2. Origin determination was renderer policy; draft-03 §4.1 makes the
   derivation order normative and calls out the unknown-origin (tarball)
   downgrade with an optional strict mode.
3. Tier→confidence mapping was unexplained; draft-03 §5.1 specifies the
   default (0.7/0.6/0.5) and requires monotonicity in tier.

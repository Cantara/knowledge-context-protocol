# Market-analysis research corpus

> Subscription tier (`access: authenticated`, `auth_scope: read:research`). Access requires an
> active plan; a metered Stripe fallback is offered. The agent presents a subscription bearer token
> or falls through to metered billing — the `payment` block declares both, in preference order.

The corpus holds weekly market-analysis reports, sector deep-dives, and model outputs. It is the
premium tier of the knowledge API — the free `docs` index describes it, but its contents are gated.

# My Project

The smallest thing that works. This project ships a five-line
[`knowledge.yaml`](./knowledge.yaml) declaring a single `overview` unit — enough for an AI agent to
know what the repository is and where to start, at Level 1 conformance.

Add depth as you need it: `validated` dates, `depends_on` ordering, `triggers`, relationships. Every
other example in [`../`](../) is this same manifest with more fields layered on.
